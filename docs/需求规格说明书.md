# Galgame 管理器需求规格说明书

| 版本 | 日期 | 适用范围 |
| --- | --- | --- |
| v0.1 | 2026-11-20 | Windows 桌面应用 MVP |

玩家可以把已经安装或解压的 Galgame 汇集到一个本地游戏库，从库里查找游戏并一键启动。首次使用时，玩家选择扫描目录、核对识别结果并确认导入。遇到多个启动入口、未识别到游戏或路径失效时，玩家可以在应用内完成配置。

本文定义玩家可观察的行为和验收条件。R01 至 R07 沿用[系统设计文档](系统设计文档.md)的需求编号，T01 至 T08 对应[开发计划](开发计划.md)的测试用例。

## 1 用户与使用范围

- **目标用户**为在同一台 Windows 电脑上管理本地 Galgame 的玩家。使用 Windows 普通用户权限，可在本机离线操作。
- **游戏来源**为本地固定磁盘或已连接的可移动磁盘。游戏应已解压或安装，并具有可由目标 Windows 系统运行的 `.exe` 入口。
- **验收环境**为 Windows 10 22H2 x64（内部版本 19045）和 Windows 11 x64。Windows 10 至少实测家庭版或专业版中的一个，发布时注明实测的系统版本、版本类别和补丁。
- **后续版本候选**包括联网补全游戏资料、账号与跨设备同步、下载与解压，以及游戏运行环境配置。

| 术语 | 含义 |
| --- | --- |
| 扫描目录 | 玩家选定的搜索范围。一个扫描目录可以包含多个游戏安装目录，也可以直接指向单个游戏目录。 |
| 游戏安装目录 | 游戏文件所在的目录，用于识别一个本地安装实例。同名游戏安装到不同目录时，可以各自入库。 |
| 启动入口 | 为某条游戏记录选定的 `.exe` 文件。 |
| 工作目录 | 游戏进程启动时解析相对路径使用的目录。默认使用启动入口所在的目录，玩家可在详情中更改。 |

## 2 功能需求

本节条目均属于首版，与第 6 节的验收用例对应。

### R01 扫描目录与扫描过程

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R01.1 | 玩家可以通过系统文件夹选择器添加一个或多个扫描目录，并从扫描列表中移除目录。 | 添加后立即显示目录路径，重启后仍可扫描。取消文件夹选择时返回原界面。移除仅作用于扫描配置。 |
| R01.2 | 玩家可以扫描一个目录或全部已保存的目录。扫描在所选范围内查找子目录中的 `.exe`，并跳过自动遍历遇到的目录联接和符号链接。 | 测试集中位于多层目录的候选可被发现。指向扫描范围外的目录联接被跳过，重叠目录的候选只处理一次。 |
| R01.3 | 同时只运行一个扫描任务。扫描中显示当前目录、已遍历的目录数、已发现的候选数，并允许取消。 | 扫描期间可继续查看和搜索游戏库。点击取消后显示反馈，当前文件系统调用结束后停止遍历。本次扫描产生的预览不进入提交。 |
| R01.4 | 遇到不可访问、已断开或扫描中消失的目录时，显示失败位置和原因。可访问的分支继续扫描。 | 在一个有效目录和一个不可访问的目录上执行扫描，结果包含有效目录的候选与失败项。如果所有目录都不可访问，提示检查连接或权限。 |

### R02 游戏识别与导入

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R02.1 | 同一安装目录的候选入口合为一条游戏项，默认标题取安装目录名。常见的嵌套程序目录可以归到上层安装目录。 | 给定一组有多个 `.exe` 的游戏和一组入口位于 `bin` 下的游戏，预览按安装目录显示。 |
| R02.2 | 应用可以预选识别依据充分的入口。遇到多个可信候选或依据不足时，提示玩家选择。已识别为安装、卸载、配置等辅助程序的文件禁止被自动预选。 | 使用单入口、带卸载程序、原版和汉化版入口并存的样本测试。玩家可以在预览中查看候选路径、接受建议或改选。 |
| R02.3 | 玩家可以勾选多项后统一导入，也可以把暂未选定入口的游戏保存为「待配置」。导入前须确认所勾选的条目。 | 只有已确认且被勾选的新条目进入游戏库。取消预览会放弃尚未确认的导入。预览显示已有记录，提交后显示新增与跳过数量。 |
| R02.4 | 确认导入时，应用须核验所选入口仍存在且位于对应的游戏安装目录内。 | 在预览打开后移走一个所选入口。提交时定位受影响的条目，保留玩家的勾选与选择，待玩家修正后重试。 |
| R02.5 | 漏扫的游戏可通过「手动添加」指定安装目录和 `.exe` 入口。应用提供一个可编辑的默认名称。 | 直接添加一款没有出现在预览中的游戏，保存后可搜索并启动。与已有记录冲突时提示已有条目。 |

### R03 游戏库与搜索

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R03.1 | 游戏库展示已保存的全部游戏，每条至少显示名称、状态和操作。对于同名游戏，可以查看安装路径以区分。 | 导入、手动添加和重启后均能看到对应记录。删除一个扫描目录后，已导入的游戏仍可在库中找到。 |
| R03.2 | 玩家可按显示名称的部分文本查找游戏。搜索支持中文、日文和英文，英文字母匹配忽略大小写。清空关键字恢复完整列表。 | 分别使用中日文片段及不同大小写的拉丁字母查询。没有匹配时显示搜索为空，并提供清空方式。 |
| R03.3 | 游戏库展示「检查中」「已就绪」「待配置」和「路径不可用」状态。应用打开、导入、保存或玩家主动刷新时检查可用性。 | 库先加载已保存记录，再更新状态。入口缺失和工作目录无效均有修复入口。已断开的磁盘重新连接后，刷新可恢复有效记录的就绪状态。 |

### R04 一键启动

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R04.1 | 对于「已就绪」游戏，玩家在游戏库点击一次「启动」即可发起启动，应用使用已保存的执行文件、工作目录和参数。 | 用测试程序记录实际收到的工作目录和参数。分别验证默认与自定义工作目录，并保留参数顺序、空参数、字面空格和引号。 |
| R04.2 | 点击启动时再次检查安装目录、入口和工作目录。请求处理中合并同一条目的重复点击。 | 入口在刷新后被移动或删除时，点击启动可收到明确提示。同一请求完成前连续点击，应用只向系统发起一次进程创建。 |
| R04.3 | 应用在收到 Windows 创建进程的结果后结束启动请求。文件丢失、权限不足或系统启动失败时，提供可操作的反馈。 | 真实游戏样本能进入预期界面。模拟失败时可看到原因，并可重新选入口、编辑工作目录或重试。 |

### R05 编辑配置与重新定位

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R05.1 | 详情页允许修改显示名称、入口、工作目录和启动参数，保存前提示无效字段。 | 空名称、安装目录外的入口和不存在的自定义工作目录会得到相应提示。修正后可以保存。重启应用后可读取新配置。 |
| R05.2 | 安装目录移动或不可访问时，保留记录并允许重新定位。选定新目录后，应用优先匹配原相对入口，必要时让玩家重新选择。 | 移动目录后使用「重新定位」，保存成功后库中仍为同一条记录且可以启动。名称和参数得以沿用。使用过自定义工作目录时，玩家确认继续使用或恢复默认。 |
| R05.3 | 保存、取消和错误反馈应明确。路径冲突时呈现已有条目并保留当前编辑内容。 | 将游戏重新定位到已入库的另一安装目录，得到冲突提示。取消编辑后再次查看，显示最后一次成功保存的配置。 |

### R06 重复扫描与记录一致性

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R06.1 | 以安装路径识别已有游戏，相同启动文件也用于识别重复项。普通 Windows 大小写不敏感路径的不同写法须归到同一记录。 | 分别使用父目录和子目录扫描同一安装，或重复扫描两次。游戏库只有一条对应记录。同名但分开安装的游戏可各自保留。 |
| R06.2 | 重新扫描可发现新游戏，已保存的名称、入口、工作目录和参数以详情配置为准。 | 手工编辑一款已导入游戏并新增另一款，再执行扫描和导入。已编辑游戏继续按原配置启动，新游戏可入库。 |
| R06.3 | 批量导入要么完整保存选定且通过校验的新记录，要么在写入失败时回滚本批次。 | 模拟批量导入过程中写入失败，已入库的记录仍可读取。修复故障并重试时，可正常保存该批次。 |

### R07 Windows 兼容性与交付

| 条目 | 需求 | 验收条件 |
| --- | --- | --- |
| R07.1 | 同一个 Windows x64 自包含 ZIP 支持在两个目标系统上解压后运行。本应用可用普通账户启动。 | Windows 10 22H2 x64 和 Windows 11 x64 使用同一发布包完成选择目录、导入、搜索、重启恢复及一键启动。至少在 Windows 10 使用未预装 .NET SDK 和 .NET 桌面运行时的环境测试。 |
| R07.2 | 管理器操作支持含有中文、日文和空格的扫描路径、安装路径及文件名。 | 在两个目标系统上用包含上述字符的路径完成导入和启动测试。旧游戏自身的区域设置及运行库要求按实际样本记录。 |

## 3 用户界面需求

首版界面使用简体中文，启动时打开游戏库。主流程为「游戏库 → 扫描目录 → 导入预览 → 游戏库 → 启动」。修复流程从游戏库条目进入游戏详情。

| 编号 | 界面 | 必要内容与操作 |
| --- | --- | --- |
| UI01 | 游戏库 | 展示搜索框、添加扫描目录和手动添加入口。每个游戏条目显示名称和文字状态，有「启动」和「详情」操作。首次打开空库时提供添加目录的直接入口。 |
| UI02 | 扫描目录 | 列出已保存的目录路径，可添加、移除、扫描所选或扫描全部。总量未知时使用不定进度，同时显示扫描计数、当前目录、跳过项和「取消」按钮。 |
| UI03 | 导入预览 | 显示游戏名称、目录、已有记录标记、候选入口和勾选状态。未选入口时显示「待配置」。点击确认前可核对本次选中的记录，提交后显示结果。 |
| UI04 | 游戏详情 | 展示游戏名称、安装目录、执行文件、工作目录和启动参数。工作目录留空时明确标注默认行为，启动参数按单项编辑。提供保存、取消及重新定位。 |
| UI05 | 键盘与显示缩放 | 关键按钮、文件选择和输入区域可通过 Tab、Shift+Tab 及常用确认键操作，焦点可见。状态由文字表达。在 1280 × 720 的可用显示空间或等效缩放下，关键操作能通过布局或滚动到达。 |
| UI06 | 反馈与恢复 | 区分空库、搜索无结果、本次扫描未发现游戏和扫描失败。数据未保存或游戏无法启动时，提示具体原因以及下一步可用操作。 |

| 游戏状态 | 判定 | 界面操作 |
| --- | --- | --- |
| 检查中 | 已加载保存的记录，应用正在检查文件和目录。 | 显示检查状态，可查看详情。 |
| 已就绪 | 记录有入口，安装目录、入口及工作目录均可访问。 | 可点击「启动」。 |
| 待配置 | 安装目录可访问，记录缺少启动入口。 | 打开详情选择入口。 |
| 路径不可用 | 安装目录、已配置入口或工作目录缺失或不可访问。 | 按原因提示刷新、重新连接磁盘或重新定位。 |

### 3.1 游戏配置字段

| 字段 | 默认值与输入规则 |
| --- | --- |
| 显示名称 | 默认取安装目录名。玩家可编辑，保存值至少包含一个非空白字符。 |
| 安装目录 | 导入时取识别出的目录，手动添加时由玩家选择。已有记录通过「重新定位」变更。 |
| 启动入口 | 可接受预选建议或自行选择安装目录内的 `.exe` 文件。允许通过预览以「待配置」状态入库，或在详情中补配。 |
| 工作目录 | 留空时使用启动入口所在目录。填写时选择可访问的目录。 |
| 启动参数 | 默认无参数。按项录入和调整顺序，保留每个参数中的空格和引号，并区分无参数与一个空字符串参数。 |

## 4 非功能需求

| 编号 | 要求 | 验收方法 |
| --- | --- | --- |
| NF01 离线使用 | 扫描、配置、搜索、持久化和启动均在本机完成。 | 断网完成从添加目录到启动测试程序的主流程。 |
| NF02 本地数据可靠性 | 保留已成功提交的游戏库和配置。写入失败、保存取消或数据库升级失败时，应保留此前的库数据，并给出可理解的提示。 | 重启应用验证恢复，使用写入失败和升级失败的测试库验证原有数据。 |
| NF03 文件访问与启动 | 扫描以只读方式访问游戏文件。运行可执行文件的入口是玩家对已配置记录发出的启动操作。应用遵循当前 Windows 用户的文件访问权限。 | 对比扫描前后的游戏目录内容。扫描并预览测试程序所在目录，确认只有执行「启动」时才创建该进程。 |
| NF04 日志与隐私 | 错误诊断保存在本机。日志仅记录失败原因、系统错误码等排查所需信息。启动参数和完整游戏清单由本地配置保存。 | 触发扫描和启动错误，检查相应日志，确认其中没有完整游戏清单或启动参数。 |
| NF05 可恢复性 | 扫描中断、路径失效、导入失败或启动失败后，玩家可以在界面继续查看已有记录，并按相应提示重试或修正。 | 分别触发可恢复故障，验证能回到可操作界面并完成重试。 |

## 5 性能需求

以下为首版建议验收目标，尚未实测。开工时用参考环境测一次基线，再确定性能验收值。参考机为 x64、4 个逻辑处理器、8 GB 内存和本地 SSD。测量使用 Release 发布包，记录设备配置、操作系统版本和测试数据规模。可移动磁盘的扫描耗时单独记录。

| 编号 | 指标 | 建议目标及测量方式 |
| --- | --- | --- |
| P01 游戏库启动时间 | 从打开应用到游戏库可搜索。 | 本机已有约 1,000 条游戏记录时，连续 5 次启动的中位数 ≤ 3 秒。入口状态在后台逐步呈现。 |
| P02 搜索响应 | 从输入关键字到列表更新。 | 在约 1,000 条记录中执行 20 次不同的查询，常规浏览和后台扫描两种场景分别统计，95% 的查询 ≤ 200 毫秒。 |
| P03 扫描耗时 | 从确认扫描到导入预览可操作。 | 本地 SSD 测试集含约 5,000 个可读目录和约 1,000 个 `.exe` 候选，扫描 3 次取中位数，目标 ≤ 15 秒。同步验证游戏库和窗口操作仍能响应。 |
| P04 扫描取消 | 从点击取消到界面响应，以及到扫描任务退出。 | 首次界面反馈 ≤ 250 毫秒。最后一个已在执行的文件系统调用返回后，目标 ≤ 1 秒退出扫描，随后可重新开始扫描。 |
| P05 启动反馈 | 从点击「启动」到界面确认收到请求。 | 在有效的本地测试入口上，反馈目标 ≤ 250 毫秒。另记系统返回进程创建结果的时间和真实游戏进入主界面的时间。 |

| 需求 | 开发计划测试 | 补充核对 |
| --- | --- | --- |
| R01 | T01、T08 | 空扫描结果、目录联接、不可访问分支、扫描中取消。 |

| R04 | T04 | 默认与自定义工作目录、参数顺序、启动请求中的重复点击。 |
| R05 | T05 | 移动盘恢复、路径迁移、工作目录复核及冲突提示。 |
| R06 | T06 | 重叠目录、保留用户设置、写入失败回滚。 |
| R07 | T07 | 同一发布包、双系统、普通用户、Unicode 路径及干净运行环境。 |
| UI01 至 UI06 | T01 至 T05、T07 | 按界面检查表操作，补测键盘、缩放和错误状态。 |

验收按开发计划覆盖至少 5 款本地游戏样本、可报告工作目录与参数的测试程序，以及用于批量扫描的合成目录。验收记录包括应用构建标识、系统版本、测试步骤、预期结果和实际结果。首版发布前须通过 R01 至 R07 的主流程和异常恢复测试，并记录两个目标系统的结果。
